## Projects (Projeler)
### Candy Crush Clone (Console Game)
**Language:** C | **Type:** Algorithm Project | **Status:** Completed

C dili ile geliştirilmiş, "break/continue" gibi akışı bozan komutlar kullanılmadan yazılmış :), tamamen **Yapısal Programlama (Structural Programming)** prensiplerine uygun bir bulmaca oyunu.

**Özellikler / Features:**
- **Dinamik Tahta:** 20x20 boyutunda oynanabilir alan.
- **Patlatma Algoritması:** Yatay ve dikey eşleşmeleri kontrol eden özel mantık.
- **Yer Çekimi:** Patlayan taşların yerine üsttekilerin kayması.
- **Test Modu:** Manuel harita girişi ile debug imkanı.
